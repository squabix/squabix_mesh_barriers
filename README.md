# SQUABIX Mesh Barriers

Make navigation obstacles and collision barriers from a mesh.

## Classes

- `MeshNavigationObstacle3D`
- `CollisionBarrier3D`

## Use

1. Add a `MeshNavigationObstacle3D` and set `mesh_instance`.
2. Press Regenerate, or turn on `generate_on_ready`.
3. Add a `CollisionBarrier3D` and set `sample` to a node with meshes.
4. Press Regenerate to build a tall barrier around the mesh.

## Demo

See it in the game: https://github.com/squabix/craftlander

## Needs

Godot 4.5 or newer.
